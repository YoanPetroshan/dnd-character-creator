**VC0 harness (tests first):** package `server/tests/tools/chartest/` (not collected by pytest; tests in `server/tests/test_chartest_harness.py`), in-process from `server/`: `spec.py` (JSON-line character spec: id, ruleset, classes [[class, level, subclass]], species, background, abilities method/assign, hp fixed/rolls, sources, overrides, equip/worn/wielded, tags; `build_draft(spec)` reuses `kitchen_sink.base_draft/fill`, filler order first/last/seeded), `matrix.py` (deterministic `generate(tier, seed, n)`; multiclass specs always satisfy 13+ in every class's primary ability unless tagged `prereq-negative`; never 3 classes outside tier T4), `checks.py` (independent oracle: reads raw data via json from `server/data/official`, `chargen/data/srd`, and the 2024 PHB markdown for ch. 1,2,4,5,6,7 read-only; returns `{check, ok, expected, actual, cite}`): proficiency bonus, ability totals and modifiers (2024 background bonuses capped at 20; 2014 species), HP fixed/rolled, spell slots (multiclass table; Paladin/Ranger round UP under 2024, down under 2014/mixed; third casters level//3; Warlock Pact Magic separate), spell DC/attack, cantrips/known/prepared/spellbook counts from class table columns, saves, skills (+expertise), passives, initiative, AC best-of (armor vs Barbarian/Monk/Draconic unarmored formulas, one at a time), speed incl. heavy-armor penalty and fly ban, attacksPerAction (Extra Attack no stacking), features vs level vs class tables, multiclass prerequisites problem iff a primary ability < 13, feat prerequisites, multiclass proficiencies, duplicate skills/tools/languages, resource numbers vs class-table columns; `weird.py` always-on detectors (absurd/negative numbers, empty sections that should not be empty, duplicates, pending after fill, unavailable cards listed for judgment, problems/warnings on a filled legal draft, pruned on a fresh draft, export gate disagreement, exports failing or PDF < 10 KB, sheet/derived/export count mismatches via the W9 matcher, resolve > 50 ms best-of-3, exceptions, idempotence, ruleset/source leakage); `cli.py` (`gen`, `run` compact one-line-per-character results, `show` ~60-line readable sheet, `explain <char> <check>` expected vs actual with inputs and citation, `finding add`). Harness tests: deterministic spec->draft; every check passes on 6 known-good drafts (fighter20, wizard20-2024, warlock7-2024, bard10-2014, Paladin 6/Warlock 2, Ranger 4/Sorcerer 3 = the PHB example 4/3/2); each check fails on a deliberately corrupted resolution; `run` on 5 specs < 10 s; checks.py imports no engine code except to call `resolve`.

**Matrix (about 400 characters, hard cap 600):** T1 single class (180: 12 classes x 3 rulesets x 5 levels with rotated level sets, subclasses/species/backgrounds/ability and HP methods rotating, filler first/seeded); T2 exactly two classes (150: ~30 pairs x 5 splits from {1/1, 3/2, 2/3, 5/5, 6/2, 10/10, 1/19, 19/1, 4/3, 11/9}, pairs incl. **Agent protocol:** one Sonnet "character tester" per batch of 10 specs works in `scratchpad/campaign/<batch-id>/`: runs `run`; for each failed check or weirdness flag runs `explain`, reads the cited source (JSON / SRD / PHB markdown lines) and classifies engine bug | oracle bug | known-gap (check ARCHITECTURE Known gaps/Deferred first) | unclear; reads `show` for 2 passing characters and looks for anything strange; reports to Opus in <= 25 lines. Findings go to `scratchpad/campaign/findings.jsonl` (`{fid, batch, char, spec, check, ruleset, expected, actual, cite, kind, severity S1|S2|S3, note}`; `fid` = hash of (check, class/subclass/feature/feat id, ruleset); duplicates merge with an occurrences count). S1 wrong number on sheet/exports/exception/export failure/blocked legal character; S2 wrong or missing feature/choice/prerequisite/count/duplicate; S3 label/text/timing. Opus deep-reviews every 5th character against the book text, every `unclear` finding and ~20% of `oracle` findings. Stopping: a tier stops after 3 consecutive batches with no new unique S1/S2; pause for fixes at >= 5 open S1; stop at 600 characters. Fix path: confirmed engine bug -> slice VF<n> (failing spec becomes a pytest case in `server/tests/test_campaign_regressions.py` first, then the fix; mixed/2014 output change -> named `REBASELINES["VF<n>"]` with an allowlist written from the rule, never `--regenerate`; 2024-only fixes behind `ruleset == "2024"`); unclear rules -> "Campaign deferred" list in ARCHITECTURE; oracle bugs -> fix the harness. Order: VC0 -> T3 -> T4 -> T2 -> T1 (after SK10) -> regression rerun -> summary in ARCHITECTURE.
