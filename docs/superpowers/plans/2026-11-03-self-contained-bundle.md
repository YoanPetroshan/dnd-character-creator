# Plan: self-contained data bundle (the app ships its 5etools data)

Opus planner audit of 2026-11-03 (read-only), condensed. Baseline when written: server 7415 passed with data (1460 passed + 5705 skipped without), root 356 passed + 8 skipped, golden 274 tests / 251 cases, HEAD edb0611.

## Goal and decisions (user, 2026-11-03)

The app must CONTAIN EVERYTHING ITSELF: a fresh clone (or a deployment for a few close friends) runs the full app without a separate `chargen.sync --official` step and without `~/.claude` paths. The user confirmed the data was publicly released, the repo is private and the app is shared only with close friends. A visual design phase comes later in a NEW chat (not part of this plan).

Planner defaults D1-D9 are ADOPTED (executors do not re-ask): D1 the bundle wins over the implicit `~/.claude` synced copy (a synced copy is used only when `DND_CAMPAIGN_ROOT` or `DND_OFFICIAL_DATA` is set explicitly); D2 `DND_OFFICIAL_DATA=none` is the new SRD-only switch and `DND_CAMPAIGN_ROOT=/nonexistent` now means "use the bundle"; D3 freeze today's data as a byte copy (a refresh to current 5etools is a later slice with a golden rebaseline); D4 keep text diffs, mark `linguist-vendored`; D5 add `Resurses/` to `.gitignore` (112 MB of D&D Beyond captures, never committed); D6 keep the UA classes `mystic` and `sidekick` (bundle mirrors `class/index.json`); D7 `waitress` as the production WSGI server; D8 hosting docs recommend Tailscale (private HTTPS), nothing is deployed by us; D9 the Dockerfile is shipped marked "untested" (Docker is not installed here), `scripts/start.sh` is the supported path.

## Key facts (verified by the planner)

- The converters read 40 files, 5,868,057 bytes (5.6 MiB, ~1 MB gzipped); biggest `backgrounds.json` 703 KB. Repo pack today 12.4 MiB.
- Building the catalog from raw files takes 0.15 s (a converted snapshot would not help and cannot round-trip int dict keys) => vendor the RAW files (option a), no snapshot.
- The synced folder mixes provenance: races/backgrounds/feats/items-base come from `5etools-mirror-3/5etools-src@main` (pulled 2026-08-24, 2026-09-27, 2026-10-09 per meta.json); spells/class/optionalfeatures are byte-identical to `~/Documents/5etools-src/data` v2.25.4 commit d2a26168. So the bundle MUST be a byte copy of `~/.claude/dnd/.data/official`; do NOT run `chargen.sync --official` first (it would change the catalog and the golden).
- Location does not change results: the same files loaded from a relocated DND_CAMPAIGN_ROOT with an empty HOME gave an identical catalog hash (13fc0149291569fb) and 340 golden/data tests passed.
- `chargen/` must not be edited (tests/test_chargen_isolation.py: byte-identical to the source repo). Bundle code goes under `server/`.
- Nothing else outside the repo is read at runtime (fonts in server/assets/fonts are tracked; frontend has no external URLs).
- Pinned counts of the full catalog: classes 12, levels 961, features 1783, subclasses 176, races 153, subraces 96, traits 1086, backgrounds 136, items 244, spells 936, feats 305, spell_twins 758, classes_2024 12. SRD-only: spells 319, races 9, feats 0, subclasses 12, levels 290, features 407.
- Shell note for executors: in zsh write `env A=1 B=2 cmd` literally (an unquoted `$E` holding `A=1 B=2` is not word-split).

## Gate for every slice

Server suite serial or `-n auto`, root suite (356 passed + 8 skipped expected), golden `server/tests/test_c_series_golden.py` passes UNTOUCHED (no rebaseline/append/regenerate: the bundle is byte-identical, any golden movement means STOP), `npm run build` stays green (only B4/B6 may touch scripts). Commits with explicit paths, never `Resurses/`.

## Slices

- **B1 vendor + manifest + bundle command (no behaviour change).** New `server/catalog/official/bundle.py` (stdlib only; `python -m catalog.official.bundle --from ~/.claude/dnd/.data/official [--check]`; `required_files`, `build`, `--check`; copy with shutil.copyfile, no exec bit, deterministic `MANIFEST.json` sorted keys with sha256/bytes/records/url/pulled_at taken from meta.json and a `bundle_sha256`; refuse missing/invalid JSON; remove stale files; build into a temp sibling then replace). Data at `server/data/official/**` (40 files + MANIFEST.json). `.gitattributes` `server/data/official/** linguist-vendored`; `.gitignore` add `Resurses/`. Tests `server/tests/test_data_bundle.py` (cases 1-9 of the planner: index-driven set, hostile index ignored, exact bytes, deterministic manifest, stale removal, missing file raises and leaves dest, invalid JSON raises, --check exit codes, real bundle integrity and record counts pinned).
- **B2 loader precedence.** `server/catalog/official/paths.py`: `BUNDLED_DIR`; `official_dir()` order: `DND_5ETOOLS_DATA` (per-file dev override) > `DND_OFFICIAL_DATA=none` (SRD-only, returns an absent dir) > `DND_OFFICIAL_DATA=<path>` > `DND_CAMPAIGN_ROOT` explicitly set and its `.data/official` non-empty > bundled (default); the implicit `~/.claude` copy is no longer read by the server; `has_official()` redefined locally; `data_source()` diagnostic ("srd-only"|"explicit"|"campaign"|"bundled"). Tests (8 cases: default with empty HOME gives the pinned full counts; `none` gives SRD counts; explicit paths; empty/nonexistent campaign root falls to the bundle; decoy under fake HOME/.claude ignored; catalog hash equality with a synced copy when present). Acceptance: default run 7415 + new passed with 0 data skips; `env DND_OFFICIAL_DATA=none ... pytest` gives 1460 + new passed / 5705 skipped; golden unchanged. Skip markers evaluate at collection so the env var must be set before pytest starts.
- **B3 docs + NOTICE.** README (setup without sync, test instructions with `DND_OFFICIAL_DATA=none`, "Refreshing the official data": `chargen.sync --official --force` then `python -m catalog.official.bundle --from ...` then full suite; a golden diff then is expected and needs a named rebaseline slice; note that chargen docstrings saying "never committed" are historical). "byte-identical to 5etools-src v2.25.4 commit d2a2616867c2e435b37e465d64cc01e2fc075ace (2026-03-25)" for spells/class/optionalfeatures; the repo's LICENSE.md is MIT (c) 2017 TheGiddyLimit and contributors; the data `_meta` records no license; game content is from Wizards of the Coast publications with source codes listed; DejaVu fonts license file; the repo is private and shared with a few friends as the user stated). - **B4 deployment.** `waitress==<current>` in server/requirements.txt (add to ALLOWED_THIRD_PARTY in tests/test_chargen_isolation.py); `scripts/start.sh` (checks .venv, builds the frontend if dist missing or `--rebuild`, `waitress-serve --listen=${HOST:-127.0.0.1}:${PORT:-8000} --threads=${THREADS:-4} app:app`, never FLASK_DEBUG); optional `scripts/setup.sh`; `Dockerfile` (multi-stage node build + python slim) + `.dockerignore` marked untested; tests: app is a WSGI callable and serves index.html with FRONTEND_DIST, THREAD-SAFETY guard (deep-hash the shared catalog, resolve 20 fuzz drafts concurrently in 4 threads, hash unchanged), `bash -n scripts/start.sh`, optional opt-in waitress subprocess test. Unit tests for the env builder, the network blocker, and a deliberately broken clone (races.json deleted) failing with a clear message.
