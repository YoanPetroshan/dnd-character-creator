### 8a — species feat choice

Tests: `catalog.races["human-xphb"]["feat_grants"] == [{"count":1,"category":"O"}]`; `catalog.races["custom-lineage-tce"]["feat_grants"] == [{"count":1,"category":None}]`; Variant Human subrace (check id; expected `human-phb-variant-phb`) `[{"count":1,"category":None}]`; SRD races: no key or [].

1. `_species_feat_pool(catalog, category, sources)`: "O" → feats with category "O"; None ("any") → category in {None,"G","O"} minus name "Ability Score Improvement" (EB, D, DG, FS excluded); filter `_feat_source_allowed`; sort by name.

## B. Slice 9 — attacks, carrying capacity, armor warnings

SRD fields (`chargen/data/srd/5e-SRD-Equipment.json`, 37 weapons): `weapon_category` Simple|Martial; `weapon_range` Melee|Ranged; `damage` `{damage_dice, damage_type.index}` (None for `net`); `two_handed_damage` only on versatile; `properties[].index` counts: two-handed 11, monk 10, light 8, thrown 8, heavy 8, ammunition 7, finesse 6, versatile 6, reach 5, loading 4, special 2; `range` `{normal, long?}`; `weight` int/float/None. Thrown melee weapons (javelin, handaxe, dagger) have `weapon_range` "Melee"; dart is Ranged with finesse+thrown. Armor: `armor_category` Light|Medium|Heavy|Shield; `str_minimum` chain-mail 13, splint 15, plate 15; `stealth_disadvantage` padded, scale, half-plate, ring, chain, splint, plate. Proficiency ids: weapons `simple-weapons`, `martial-weapons`, specific ids (set `_SPECIFIC_WEAPON_PROFICIENCY_IDS` in resolve()); armor `all-armor`,`light-armor`,`medium-armor`,`heavy-armor`,`shields`. Fighting-style selections: Fighter cid `class:fighter:1:feature:fighter-fighting-style` ids like `fighter-fighting-style-archery`; Ranger `class:ranger:2:feature:ranger-fighting-style` (`ranger-fighting-style-archery`); Paladin `class:paladin:2:feature:paladin-fighting-style` (`fighting-style-dueling`); detect: any selected id in a choice whose cid contains `fighting-style` ending in archery/dueling/two-weapon-fighting/great-weapon-fighting/defense. (Slice 2 already added `CLASS_FEATURE_EFFECTS` and `engine/features.py` with fighting-style effects stored — REUSE that detection rather than duplicating; Defense AC is already done, so skip 9c.)

New `server/engine/attacks.py` (pure functions, no catalog). Ability: Ranged without finesse → DEX; finesse (melee or dart) → higher of STR/DEX modifier (tie → STR); melee incl. thrown melee → STR. Proficient if (`simple-weapons` and category Simple) or (`martial-weapons` and Martial) or specific `weapon_proficiency_id(item_index)`: crossbow-light→crossbows-light, crossbow-hand→hand-crossbows, crossbow-heavy→crossbows-heavy, else index+"s" (`WEAPON_PROFICIENCY_ID_OVERRIDES` in reference_data.py). `attackBonus` = ability mod + (prof bonus if proficient) + 2 if Archery and Ranged. `damage` = `f"{dice}{mod:+d}"` (bare dice when mod 0); Dueling +2 when Melee and not two-handed; `net` → None. `versatileDamage` (versatile only) = two_handed_damage dice + mod, never Dueling. `offhandDamage` (Melee and light only) = dice + min(mod,0); with Two-Weapon Fighting dice + mod. `range` "20/60" when normal and long exist else normal as string ("5"). `notes` in order: "two-handed","heavy","ammunition","loading","reach","thrown", then "Great Weapon Fighting: reroll 1s and 2s" (two-handed/versatile with GWF), "Dueling: only with no other weapon" when applied. Out of scope (disclose): Dueling hand check, Weapon Mastery, magic items, Monk martial arts, feat attacks, unarmed strike. Output: `derived.attacks` list, one per distinct equipped weapon index, first-seen order: `{"itemId","name","ability","proficient","attackBonus","damage","damageType","versatileDamage","offhandDamage","range","notes"}`. Functions: `weapon_attack(item, modifiers, prof_bonus, proficiency_ids, styles) -> dict|None` (None for non-weapons) and `attacks_from_gear(items, modifiers, prof_bonus, proficiency_ids, styles)` (dedupes by index). Equipped weapons come from `equipped_items` after granted equipment is appended.
Carrying capacity: `carrying_capacity(str_score, size)` in derived.py = STR×15×size multiplier (Tiny 0.5, Small/Medium 1, Large 2, else 1); `equipment_weight(entries, items)` = Σ qty×(weight or 0) over `sheet.equipment.granted/chosen/added`, rounded 2 dp; `derived.carryingCapacity = {"capacity","pushDragLift"(2×),"carried","overCapacity"}`; size from `sheet.species.size` (8d) else race size else Medium.
Armor warnings: `armor_warnings(equipped_items, scores, proficiency_ids) -> (warnings, stealth_disadvantage)` in equipment.py: `armor-not-proficient-{index}` (Light needs light-armor|all-armor, Medium medium-armor|all-armor, Heavy heavy-armor|all-armor, shield `shields`); `armor-strength-{index}` when str_minimum > STR (message: speed −10 ft; do NOT change derived.speed); `armor-multiple-body` when >1 non-shield armor; `derived.stealthDisadvantage` = any equipped armor with stealth_disadvantage. Non-blocking `warnings`. Proficiency set = union of `proficient_armor` and `proficient_weapons` from resolve(), computed after the class proficiency loop (~line 3080); build `derived` after that.
Wiring/exports: resolve.py gathers styles from `choices`, computes attacks from `modifiers`, `prof_bonus`, `proficient_weapons`, adds `attacks`,`carryingCapacity`,`stealthDisadvantage` to `derived` and armor warnings to `warnings`; export.py passes the three keys through (next to armorClass ~line 25); markdown_export.py and pdf_export.py add an "Атаки" section (line per attack: `name: +5, 1d8+3 slashing (versatile 1d10+3)`) and `Носимост: carried/capacity lb` (the two files mirror each other independently by convention); frontend types.ts add `Attack`, `CarryingCapacity` and `Derived` fields; UI display optional (plain list on ExportPage at most, no styling); run `npm run build`.
