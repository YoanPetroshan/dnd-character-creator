## 2. Shared design
Catalog (new fields on `_feat_from_5etools`, next to `"saving_throw_choices"`): `"innate_spells"`: list in the race shape `{name, spell_id, level, uses, ability, variant}` (`level` None for key "_", int for numeric keys; `uses` one of "at-will"|"1/day"|"prepared"|"ritual"; ability via `_innate_spell_ability`, except "inherit" stays literal lowercase "inherit"). `"spell_choices"`: list of `{variant, level, uses, ability, count, filter: dict|None, from: list[str]|None}` (slices 3–5). `"spell_variants"`: list of names, [] unless multiple entries all carry `name` (slice 4).
Resolve helpers in `engine/resolve.py`: `_feat_cid_prefix(feat)` = `feat.get("_asi_origin") or f"feat:{feat['index']}"` (same prefix `_feat_choice_templates` uses). Extract `_innate_entry_to_sheet(entry, catalog)` from `_species_innate_spells`' loop body (identical output; refactor species to call it; race tests must still pass). `_feat_innate_spells(feats, catalog, choices)` returns sheet entries = `_innate_entry_to_sheet(...)` plus `"featId": feat["index"]`. Append to `innate_spells` at resolve.py ~2702: `innate_spells = _species_innate_spells(...) + _feat_innate_spells(resolved_feats, catalog, choices)` (`choices` final there). Do NOT filter by character level (matches race behaviour).
