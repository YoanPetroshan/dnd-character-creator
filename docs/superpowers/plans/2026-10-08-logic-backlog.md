## Slice 1. Draft & API robustness (H, S)
Evidence: `resolve()` raises AttributeError (Flask 500) for `preferences.usePrerequisites: true` (bool instead of dict) and for a top-level JSON array draft. Silent bad inputs: `level: 2.5` → 2, ability "15" → 10, `equipment.added:[{"qty":"x"}]` ignored. No JSON error handler: ExportPage.tsx calls `resp.json()` on an HTML 500 and shows a SyntaxError. Nothing dispatches `RESET` — no "new character" button; a stored draft that crashes the server traps the user. `loadInitial` (frontend/src/DraftContext.tsx) merges stored draft with defaults one level deep; no draft schema version. No export/import of draft JSON (iOS evicts localStorage after ~7 days). Frontend `canExport` blocks on pending equipment choices while the server gate (`_pending_export_problems`) excludes them — gates disagree.
Approach: `normalize_draft()` type-coercion pass at top of `resolve()` + Flask `errorhandler(Exception)` returning JSON (frontend shows a readable message). Frontend: deep-merge with defaults + `draftVersion` field; HomePage "New character" (with confirm), "Download draft (.json)" / "Upload draft (.json)" (works on iOS: use file input + Blob/share like export), and a "Reset draft" button inside the resolve-error banner; make the frontend export gate equal to `_pending_export_problems`. Tests: malformed-draft matrix for resolve and /api/resolve (no 500, JSON errors); frontend via build + browser check.

## Slice 2. Derived-stat bugs (H, M)
Wrong numbers found: Barbarian 20 DEX19 CON16 AC 14 (should be 17, Unarmored Defense not modelled); Monk 5 DEX16 WIS15 AC 13 (should be 15) speed 30 (should be 40); Draconic Sorcerer 6 HP 38/AC 12 (should be 44/15, Draconic Resilience); Fighter Defense style in chain mail AC 16 (should be 17) — fighting-style picks have no effect anywhere; `derived.skills` ignores `sheet.expertiseSkills` (`skill_scores()` has no expertise arg); `derived` lacks initiative (only Markdown computes it), passive Insight/Investigation, Jack of All Trades/Remarkable Athlete; Barbarian 20 Primal Champion (+4 STR/CON, cap 24) missing.
Approach: small `CLASS_FEATURE_EFFECTS` table in `reference_data.py` keyed by feature/subclass index (AC formula alternatives, speed bonuses, HP per level, half-proficiency rule, ability cap raises); `armor_class_from_gear` takes candidate base formulas and returns the max, formula applies only with no body armor; fighting-style AC/attack effects (Defense +1 AC when armored; leave Archery/Dueling attack bonuses for the attacks slice but store the effect); add `initiative` and passives to `derived`; pass expertise to `skill_scores`. Tests: one hand-computed sheet per effect.

## Slice 3. Official race conversion gaps (H, M)
Evidence in `official_source.py`: PHB Human gets no +1 to all abilities (bonus lives in a nameless 5etools subrace; all 5 nameless base subraces — Human, Dragonborn, Half-Elf, Half-Orc, Tiefling, PHB — are dropped); 46 races with `lineage:"VRGR"` (most MPMM races, e.g. aarakocra-mpmm, goblin-mpmm) get no ASI (should offer +2/+1 or +1/+1/+1); Custom Lineage `{"choose":{"amount":2}}` dropped; 9 subraces with `choose` ability entries get nothing (Variant Human sheet abilities equal base; SCAG tiefling variants); subraces never carry `ability_bonus_options`; `darkvision` (77 races, 9 subraces) never reaches `sheet.senses` (SRD Darkvision traits neither); subrace speed overrides/non-walk speeds lost (Wood Elf 35 → 30, Sea Elf swim lost); 7 Dragonborn-style `resist:[{"choose":...}]` races not offered as a choice.
Approach: merge nameless subraces into the parent race; map `lineage:"VRGR"` and `amount` onto the existing 2024 background ASI envelope shape; emit `ability_bonus_options` on subraces and make `_species_ability_bonus_choice_template` consume it (it already loops race+subrace); `speed` as dict `{walk,fly,swim,climb}` with subrace override, keep `derived.speed` = walk; `senses` from `darkvision` merged via the existing higher-range-wins rule; resist-choice Choice. Do NOT run concurrently with Slice 4 (both touch species code in resolve.py).
