# Round-2 audit (Opus, 2026-10-09): findings and executable slices

Method: 2,000 random drafts (1,200 single-class 12 classes × levels 1/3/5/11/20; 800 multiclass total level 5/11/20) × species (153) × backgrounds (136) × ruleset 2014/2024/mixed × sources; every pending choice auto-filled with random enabled options routed to the page bucket the frontend would use. Clean: 0 exceptions, 0 duplicate choice/option ids, 0 count>options, every choice shown on exactly one page, 0 unsatisfiable choices, 0 export failures (415 YAML/MD, 140 PDF). Resolve p50 1.2 ms, p95 2.9 ms, worst 34 ms; level-20 four-class 7 ms/66 KB; 12×level-20 15 ms/563 KB. Hand-checked HP/AC/saves/slots/DC for 7 multiclass builds: correct. Level-down 12 classes × subclasses × ASI-or-feat: 0 blocking problems, everything to `pruned`. Fuzz (non-JSON, arrays, nulls, level 1e9/-5, 1,000 duplicate classes, 100k selections, 50k choice keys, 20k items, qty 1e30, 3,000-deep nesting, 5 MB name, emoji/CJK): no 500s.

Rules for executors: TDD where logic; full suites green (`cd server && ../.venv/bin/python -m pytest -q`; root `cd /Users/yoanpetrov/dnd-character-creator && .venv/bin/python -m pytest -q`; `cd frontend && npm run build`); no visual design (structural/functional UI only); browser-check UI changes at 375px (preview_start "backend" — restart for current code — and "frontend-dev"; localStorage key "dnd-builder-draft-v2"; reset viewport to "desktop"; clear test drafts; stop servers); update ARCHITECTURE-CURRENT-STATE.md; commit per finding/slice with trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Re-verify each repro before fixing; if a finding is already fixed or wrong, say so.

## Findings

F1 HIGH/S — `_is_asi_eligible_feat` (resolve.py ~2423) accepts only `category == "G"`; PHB/XGE/TCE feats have category `''` (42+15+15), so under 2014 the ASI feat pool is only the 15 AU feats (Great Weapon Master/PHB, Lucky, Sharpshooter/PHB, War Caster/PHB never offered); under 2024 Origin feats (`O`) are excluded though 2024 lets you take any feat you qualify for at an ASI level. Repro: `{ruleset:"2014", classes:[{classId:"fighter",level:4}], species:{id:"human"}, background:{id:"acolyte"}}` → `class:fighter:4:asi` has 15 `feat:*-au` entries only. Fix idea: ruleset-aware eligibility (category `''` for 2014/mixed, `G` and `O` for 2024/mixed, `EB` only at the level-19 slot; exclude literal "Ability Score Improvement"); update ASI template and `_resolve_asi_selected_feats` together; re-baseline option-count tests. NEEDS OPUS PLAN (RAW rule change touching ASI walk, prerequisites, held-feat state, duplicates).
F2 MEDIUM/S — an ASI feat pick silently disappears when ruleset/sources change (Fighter 4 `feat:actor-xphb` then ruleset "2014" or sources ["phb"]): choice back to pending with `selected:[]`, no `pruned`, no problem, `sheet.feats` []. Spells keep an already-selected spell offered. Fix: in `_feat_offered`/ASI templates keep offering an already-selected feat (same rule as spells); same for species-feat pools.
F3 MEDIUM/S — a selected species/background hidden by Sources becomes a blocking problem while UI labels it "(скрит от текущите филтри)"; ruleset-only hiding still resolves. Repro: `sources:["srd"]` + species `goblin-psz` + subspecies `goblin-psz-ixalan-psx` → `unknown-species` + redundant `subspecies-mismatch`; same for background `urchin-phb`, subspecies `tiefling-phb-dispater-mtf` under `phb,xge,tce`. DECISION (taken by the orchestrator, default): treat source-hidden like ruleset-hidden — still resolve the selected record and add a warning (`source-hidden-species` etc.); never emit `subspecies-mismatch` when the species itself is unknown; keep `unknown-*` problems only for ids that don't exist in the full catalog.
F4 MEDIUM/S — subclass below its unlock level stays applied (`fighter` level 1 + `champion` shows Champion; `wizard` 1 + `bladesinging-tce` grants light armor) — happens on level-down since ClassPage hides the select but keeps `subclassId`. Fix: when `level < SUBCLASS_UNLOCK_LEVEL` ignore `subclassId` in resolve() (features, SUBCLASS_PROFICIENCIES, spells, sheet) and add a `pruned` entry.
F5 MEDIUM/S — blocking problems visible only on ExportPage (`multiclass-prerequisite-unmet-*`, `total-level-exceeded`, `feat-duplicate-*`, `point-buy-*`, `unknown-species`, `duplicate-class`); StepNav badges count only pending choices; UI clamps each class to 20 but never the total (Fighter 15 + Wizard 10 → `total-level-exceeded`, proficiencyBonus falls back to 2). Fix: map problem-id prefixes to steps, render them at the top of each page and add them to the badge count; ClassPage blocks raising a level once the total reaches 20.
F6 MEDIUM/S — `ChoicePicker.toggle` builds the next selection from `choice.selected` of the last resolution (debounced 150 ms + network); two taps within that window on a count-2 list lose the first pick (likely on phones over LAN). Fix: reducer action `TOGGLE_CHOICE_OPTION {source, choiceId, optionId, count}` computing the new selection from the draft's stored array (or pass the draft's selection into ChoicePicker).
F7 MEDIUM/S — unknown/garbage class id in stored/uploaded draft crashes ClassPage (white page, persists): `/api/catalog/class/<bad>` 404 `{error}`, ClassBlock still `setClassDetail(data)` then `Object.entries(classDetail.levelFeatureCounts)` throws; no error boundary; `mergeDraft` passes `classes:[null]`/non-objects through. Repro: upload `{"classes":[{"classId":"artificer","level":1,"choices":{}}]}` and open /class. Fix: check `r.ok`, validate element shapes in `mergeDraft` (drop malformed class/added-item entries), add a top-level ErrorBoundary offering download + reset.
F8 MEDIUM/M — phone usability of big option lists: fresh Wizard 20 ClassPage renders 956 checkbox rows (spells-known 338, each ASI 115, Bard spells-known 157, Skilled 49); all pending cards start expanded; no search; disabled mixed with enabled; species 153 radios. Fix: ChoicePicker filter input when >20 options, spells grouped by level, disabled options collapsed under a toggle, SpeciesPage search box, only the first pending card starts expanded.
F9 LOW-MED/S — export gate allows empty/incomplete character (`POST /api/export/yaml {}` → 200, level 0, null class/species/background; Barbarian without species exports speed "—"). Fix: `_pending_export_problems` and frontend `canExport` require ≥1 class, species and background (gate only, not resolve problems).
F10 LOW-MED/XS — ruleset 2024 + "Само SRD" (or `phb,xge,tce`) leaves 0 backgrounds (`ruleset_allows` hides the only SRD background Acolyte, tagged 2014). Fix: hint when filtered list is empty or exempt SRD from the 2024 background hide (prefer the exemption + warning).
F11 LOW/S — manual HP rolls outside 1..hit die silently replaced by the average (Fighter 4 rolls `{2:7,3:0,4:11}` → HP 29). Fix: `hp-roll-invalid-*` warning; add a level-1 roll input for non-primary classes.
F12 LOW/XS — level/HP number inputs ignore NaN so backspace snaps back (3→15 passes through 1, briefly showing pruned messages). Fix: local string state, commit on blur/Enter.
F13 LOW/XS — standard-array selects lock once all six values are assigned (each offers only its own). Fix: list all six values, swap with the ability currently holding the chosen one.
F14 LOW-MED... LOW/XS — `sheet.spells[i].spellSaveDC` null for subclass-only casters (Arcane Trickster/PHB, Eldritch Knight, Shadow/Elements Monk XPHB with always-prepared Minor Illusion). Fix: no spells entry for a class without spellcasting ability, or use the subclass's ability (WIS for Monk XPHB).
F15 LOW/XS — no `MAX_CONTENT_LENGTH` (50k junk choice keys → 5 MB response, 5 MB name echoed); HomePage uses `pruned` choiceIds as React keys (can repeat). Fix: `app.config["MAX_CONTENT_LENGTH"] = 1_000_000`, cap `pruned` at 200 entries (add a count line), add "Изчисти отпаднали избори" button deleting stale selections from the draft.
Known gaps re-confirmed: innate spell ability `{"choose":[…]}` (Elf/XPHB Drow) has no choice and isn't exported; 2024 classes run on the 2014 SRD chassis; EK/AT no third-caster slots; iOS touch share after `await fetch` may lose user activation (falls back to download) — real-device check outstanding.
